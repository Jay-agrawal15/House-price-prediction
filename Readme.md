# 🏡 House Price Prediction

## 🚀 Live Demo
Click below to try the deployed model on Streamlit:

🔗 **https://jayagrawalhouseprice.streamlit.app/**

This project focuses on predicting house prices using machine learning techniques. It includes data cleaning, exploratory data analysis (EDA), feature engineering, model building, and evaluation using multiple regression algorithms. The final model was developed using XGBoost with optimized hyperparameters and achieved strong performance.

## 📌 Project Overview

- Performed exploratory data analysis (EDA)
- Cleaned and preprocessed raw housing data
- Engineered new features to improve model accuracy
- Applied multiple regression models
- Selected **XGBoost** as the final model after tuning
- Achieved an **R² score of 0.82** on the test dataset

## 🧠 Machine Learning Models Used

- Linear Regression
- Lasso & Ridge Regression
- Random Forest Regressor
- Gradient Boosting Regressor
- **XGBoost Regressor (Final Model)**

## 📊 Technologies Used

- Python
- Scikit-learn
- XGBoost
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📈 Results

- Final XGBoost model achieved **R² = 0.82**
- Feature engineering and hyperparameter optimization significantly improved prediction performance
- Includes visualizations for data insights and model evaluation
